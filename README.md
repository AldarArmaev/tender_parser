# Tender Parser

Парсер Excel-файлов закупочных процедур с загрузкой в PostgreSQL.

## Быстрый старт

### Установка
```bash
git clone https://github.com/username/tender_parser.git
cd tender_parser
python -m venv venv
source venv/bin/activate 
pip install -r requirements.txt
```
